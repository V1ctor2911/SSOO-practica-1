# SSOO - Práctica 1

**Descripción del Proyecto**
Este repositorio contiene la primera práctica de la asignatura de Sistemas Operativos (SSOO). El objetivo principal es la implementación en C de [AÑADIR: breve descripción, ej. un intérprete de comandos básico, gestión de procesos, o simulación de llamadas al sistema], asegurando un manejo eficiente de los recursos y la memoria.

**Tecnologías y Entorno**
* Lenguaje: C
* Sistema Operativo: Linux (Desarrollado y testeado en Ubuntu)
* Herramientas: GCC, Make, Git
* Documentación: LaTeX

**Instalación y Compilación**
1. Clona este repositorio en tu máquina local:
   `git clone https://github.com/V1ctor2911/SSOO-practica-1.git`
2. Navega al directorio raíz del proyecto:
   `cd SSOO-practica-1`
3. Compila el código fuente utilizando el archivo Makefile incluido:
   `make` 
   *(Alternativa manual: `gcc -Wall -o practica src/main.c`)*

**Uso y Ejecución**
Una vez compilado correctamente, ejecuta el programa desde la terminal indicando los parámetros necesarios:

`./practica [argumento_1] [argumento_2]`

*Ejemplo de uso:*
`./practica -f archivo_prueba.txt`

**Estructura del Repositorio**
* `src/`: Archivos de código fuente (`.c`).
* `include/`: Archivos de cabecera (`.h`).
* `docs/`: Memoria explicativa de la práctica en formato PDF.
* `Makefile`: Reglas de compilación y limpieza del proyecto.
